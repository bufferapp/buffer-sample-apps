Privacy

How this sample app handles data.

Draft Queue uses Buffer OAuth only to read the connected account's organizations and channels and to create a draft requested by the user.

Access tokens are kept in an encrypted, HTTP-only session cookie and are not exposed to browser JavaScript. This sample does not use analytics, sell personal data, or persist Buffer data in an application database.

Disconnecting clears the local session. For questions about a deployment of this sample, contact that deployment's operator.
