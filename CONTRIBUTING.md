# Contributing

Thanks for helping improve the Buffer sample apps.

## What we accept

- **Pull requests for fixes and improvements** to the existing samples are welcome.
- **New samples** aren't accepted at the moment. If you have an idea for one, please [open an issue](../../issues) instead.
- **Bugs and suggestions** can be reported by [opening an issue](../../issues).

## Guidelines

- Keep each sample small and copyable. A change should teach one clear Buffer API practice.
- Include a test when you change behavior.
- Avoid adding frameworks or dependencies unless they make the example clearer.
- Before opening a pull request, run the sample's checks. For the Node.js samples, that's `npm test` and `npm run lint`.
- Never commit `.env` files, certificates, client secrets, sessions, or real tokens.
